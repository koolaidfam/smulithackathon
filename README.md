# Canon

The company brain for a law firm. Horizon scanning already says a circular landed. Canon answers which templates, playbooks, checklists, workflows and past advisories still assume the old rule, then routes a named lawyer who can dispose of the change.

Hackathon build. Not a production control system.

## Run it

```bash
npm install
npm run dev
```

The dev server binds to the LAN so an iPad can open the laptop URL.

```bash
npm run build
npm run preview
```

Then Add to Home Screen (Safari) or Install app (desktop Chrome).

## Demo path

The clock is frozen at **5 Sep 2026**. MAS Notice 626 commences on **1 Oct 2026**.

1. Home. Drag the brain. Click a node. Nothing is flagged until a lawyer acts.
2. Leave the instrument on **MAS Notice 626**. Click **Publish amendment**. The walk lights documents, playbooks, workflows, advisories and teams.
3. Open **KYC gate automation**. Silent failure. Jamie Koh (intern) cannot dispose. The task climbs to Marcus Hale.
4. Open **Coverage**. The share allotment checklist mentions S$20,000 as a capital floor. A keyword sweep would have flagged it. There is no edge to Notice 626.
5. The lunch-and-learn is an embedding suggestion. Confirm the edge only if a human agrees.
6. Switch the instrument to the beneficial ownership consultation. Mapped. Nothing is marked flagged.
7. Open **Horizon**. Australia is off the list. Add **ASIC AML/CTF Rules** by hand, then publish. A parallel jurisdiction does not enter the scan until a lawyer says so.

## What the brain will not do

- Flag from similarity. Only confirmed stored edges carry a flag.
- Draft substantive legal text. Mechanical edits get a suggestion and a citation. Judgement calls get the parameter delta and a named lawyer.
- Redline a formal instrument or an executed contract.
- Propagate from a draft consultation paper.
- Choose the firm's horizon. The lawyer picks the sources.

## Layout

Paper and ink, from the team whiteboard. Desktop keeps the inspector beside the graph. iPad uses a floating panel or a sheet, with a bottom tab bar in portrait.
